# 蹭饭图生成器

一个零依赖的「毕业去向」可视化网页 —— 输入同学姓名和大学，自动在中国地图上标注。

## ✨ 功能

- **三种添加方式**：手动添加 / 批量文本 / Excel 导入
- **内置 200+ 大学坐标**：找不到学校时输入城市也能定位
- **本地保存**：刷新页面数据不丢
- **图片导出**：一键保存为高清 PNG
- **数据导出**：支持导出为 Excel

## 🚀 部署到 GitHub Pages（小白教程）

### 第一步：注册 GitHub 账号（如果还没有）

打开 https://github.com 注册一个账号。

### 第二步：创建仓库

1. 登录后，点右上角 **+** → **New repository**
2. Repository name 填：`cengfan`（名字随便起）
3. 选 **Public**（公开）
4. 勾选 **Add a README file**
5. 点 **Create repository**

### 第三步：上传文件

1. 在新仓库页面，点 **Add file** → **Upload files**
2. 把本地的 `index.html` 拖进去（直接拖文件到网页）
3. 等上传完，点 **Commit changes**

### 第四步：开启 Pages

1. 仓库页面点上面的 **Settings**（设置）
2. 左边菜单找到 **Pages**
3. Source 选 **Deploy from a branch**
4. Branch 选 **main**，文件夹选 **/(root)**
5. 点 **Save**

### 第五步：等 1-3 分钟

刷新 Pages 页面，会出现一行绿色的网址，类似：

> 🌐 https://你的用户名.github.io/cengfan/

点开就能用了！把这个链接发给同学，全班都能用。

## 💡 怎么用

1. **手动添加**：左边的「添加同学」一栏填姓名 + 大学
2. **批量导入**：
   - 点「下载 Excel 模板」拿到格式
   - 在 Excel 里填好（姓名、大学、城市可选）
   - 回到网页上传文件
3. **批量文本**：每行一个同学，格式 `姓名,大学`（中文逗号也行）
4. **保存图片**：点右下方「保存为图片」下载 PNG

## 🆘 找不到我的大学怎么办？

在「城市」一栏填上学校所在的城市，比如「上海」「西安」等。
内置了 300+ 主要城市坐标。

## 🔒 隐私

- 所有数据存在你自己的浏览器（localStorage）
- 不上传任何服务器
- 别人用这个网页也不会看到你的数据
